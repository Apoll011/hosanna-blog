# Finding anything in a large Hosanna library

After a few years of ministry, "search by title" is not enough. You remember the key, the season, the folder someone made in 2022, or that the song has a number in the hymn book.

Hosanna's song filters stack. Service filters do too.

## Song library filters worth using

Open the filter sheet from the library (or folder browser):

- **Tags** — Christmas, communion, kids, slow. Match all or any.
- **Key** — pulled from ChordPro `{key}` metadata.
- **Folders / collections** — structural homes for repertoire.
- **Song number** — numbered vs unnumbered when you still think in hymnals.
- **With chords only** — hide lyric-only sheets when the band is hunting charts.
- **Sort** — title, artist, number, updated, added.

Active filters show as chips. Clear them in one tap when you are done.

Search still works on top: title, artist, and optional lyric text if you enable it.

## Service list filters (new)

Services used to be a long date-sorted list with a search box. That breaks down once you archive old Sundays and plan ahead.

The services filter sheet covers:

- **When** — upcoming, past, today, this week, this month
- **Status** — active, archived, or both
- **Plan** — has songs, has notes, empty plan (unfinished)
- **Sort** — date or name

Default stays "active only," newest dates first—the same mental model as before, just with an escape hatch.

## A weekly habit

Friday: filter **upcoming + has songs**, walk each service once.  
Monday: filter **past** if you archive, or leave them active until the season ends.

Empty states no longer pretend a sync button will invent repertoire. If the library is empty, sync from Studio. If filters hid everything, clear the chips.
